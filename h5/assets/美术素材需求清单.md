# 绿色循环圈外传 H5：美术素材需求清单

配合方式和出图流程见 [art/美术配合说明.md](../../art/美术配合说明.md)。
配套文件：[素材清单.csv](素材清单.csv)（277 行，每个单位一行，含原图模型参考、优先级、动作需求）。
接入方式：做好的图放进 `h5/assets/`，在 [manifest.js](manifest.js) 里按"素材 key"登记，游戏会自动替换占位图形，可以逐个替换。

---

## 1. 技术路线：建议"3D 建模 → 预渲染 2.5D 精灵图"

| | A. 3D 建模，渲染成精灵图（推荐） | B. 网页实时 3D（three.js + glTF） |
|---|---|---|
| 画面 | WC3 式斜 45° 视角，效果由离线渲染决定，可以做得很精致 | 真 3D，可以旋转镜头 |
| 手机性能 | 好：每个单位只是一张图，几百只怪也流畅 | 一般：几百个带骨骼动画的模型，中低端手机吃力 |
| 和现有代码的关系 | 直接接入，只需在 `manifest.js` 里登记 | 渲染层要整体重写 |
| 工作量 | 建模 + 绑骨 + 批量渲染脚本（Blender 一键出 8 方向图） | 建模 + 绑骨 + 导出 glTF + 重写渲染 |
| 以后能不能换成 B | 能：同一批 3D 模型直接导出 glTF 即可 | — |

**结论：** 先做 3D 模型（这是长期资产），用 A 方案出图上线；以后要做真 3D，模型可以直接复用。

## 2. 统一规格

| 项目 | 规格 |
|---|---|
| 视角 | 正交相机，俯角约 50°（接近 WC3 默认镜头）；光源左上方；描边可选 |
| 方向 | 会移动的单位（怪物、守卫者）8 方向；塔和英雄塔 1 方向，攻击时只需朝向变化的话再加 8 方向 |
| 动作与帧数 | 待机 4–8 帧，行走 8 帧，攻击 6–8 帧，死亡 6 帧，施法 6–8 帧（英雄） |
| 输出 | 由出图脚本自动生成：精灵表（WebP，透明底）+ JSON 帧信息；脚底中心在画布高度 70% 处 |
| 渲染尺寸（@2x） | 普通怪 128px，BOSS 256px，塔 160px，英雄塔 192px，守卫者 128px（精英怪用普通怪的图放大 130%，不单独出图） |
| 命令面板图标 | 128×128 方图，WC3 风格的金色边框可以由程序统一叠加，图标本身不带边框 |
| 头像（信息面板） | 256×256，半身像 |
| 命名 | 文件名用"素材 key"（`unit_hfoo.png`、`tower_箭塔_max.png` 等），和 manifest 对应 |

### 可读性规则（玩法要求，必须遵守）
- **护甲颜色**：怪物身上要有明显的护甲色点缀（铠甲、光环或脚底圈都可以）：
  - 物理 = 橙 `#ff9a3c`
  - 魔法 = 蓝 `#5aa8ff`
  - 抗性 = 绿 `#5fd35f`
  - 神圣 = 金白 `#fff27a`

  玩家要一眼看出该用什么塔。
- **攻击类型颜色**：塔的弹道和特效用攻击类型的颜色：
  - 普通 = 白
  - 穿刺 = 橙
  - 魔法 = 蓝
  - 混乱 = 紫
  - 英雄 = 金
- **精英怪**：同一个模型放大到 130%，加粉紫色光环特效。不需要单独建模，程序负责缩放。
- **BOSS**：体型更大，加红色描边或脚底红圈。

## 3. 制作批次

| 批次 | 内容 | 数量 |
|---|---|---|
| 第 1 批（可玩性最低要求） | 守卫者、4 个英雄塔、28 种塔各 1 个外观、第 1–10 波的 40 只怪物和 3 个 BOSS（清单：`tools/blender/batch1.csv`） | 76 个模型 |
| 第 2 批 | 塔的中级 / MAX 外观（每种塔 3 档）、第 11–30 波怪物 + 20 / 30 波 BOSS | 约 110 个 |
| 第 3 批 | 第 31–48 波怪物、40 / 48 波和最终 BOSS（4 色龙 + 魔王）、技能特效 | 约 80 个 |
| 第 4 批 | 其余 40 个英雄（P2，等对应英雄的玩法实装后再做） | 40 个 |

**省工技巧：** 198 只怪物只用了 125 种原图模型。很多怪是"同一模型的强化版"（如"强盗 / 强壮的强盗"），只需做一个基础模型，再通过换色、加装备、放大来做变体。清单里"原图模型参考"一列相同的行可以共用一套骨骼和动画。

## 4. 单位设定

### 4.1 守卫者（建造者）
- **循环圈守卫者**：原图用的是火焰熊猫酒仙模型（缩放 0.42）。
- 设定：圆滚滚的熊猫工匠，背着建造工具和酒葫芦，身上有火焰纹样。
- 动作：
  - 行走：8 方向，移速很快（500），要有小跑感
  - 建造：用锤子敲击
  - 闪烁：火焰瞬移特效
- 它是玩家在地图上唯一能操控的单位，要辨识度高，比怪物醒目。

### 4.2 英雄塔（第 1 批：4 个）
英雄塔不会移动，站在一个底座上。底座随等级加装饰：1 / 10 / 20 / 30 级各一档。

## 5. 特效与图标
- **弹道**：普通 / 穿刺 / 魔法 / 混乱 / 英雄 5 种基础弹道，加扫射射线、闪电链、毒箭 3 种特殊弹道。
- **命中与范围特效**：溅射圈、晕眩星星、减速冰霜、护甲碎裂、燃烧、冰冻。
- **光环**：4 种塔光环，5 种精英光环（专注 / 减攻速 / 弱击 / 耐久 / 邪恶）。
- **命令面板图标**：
  - 通用：移动、停止、闪烁、建造、随机建造、使用木材、升级、回收、返回、力量 / 敏捷 / 智力、学习技能
  - 28 种塔各 1 个
  - 4 个英雄各 1 个，外加各自 4 个技能图标
- **头像**：守卫者、4 个英雄、28 种塔。怪物可以直接从模型截图。
- **界面**：控制台石质边框、顶部资源图标（金币 / 木材 / 人口）、小地图边框。
