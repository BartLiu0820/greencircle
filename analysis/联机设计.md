# 联机设计（H5 复刻）

思路照 `联机调研-pokebonk.md` 第二节：服务器只管大厅和信令，对局走 WebRTC 全网状直连，按"谁刷的怪谁算"分别权威，不做锁步。
涉及的文件：`server/`（大厅 + 信令）、`h5/net.js`（大厅界面 + 连接层）、`h5/game.js` 的"联机对局同步"一节（`MP`）。

## 1. 房间流程

1. 开始菜单 →「联机（房间码）」：填信令服务地址（默认本机 `http://<页面主机>:8787`），建房或输入 4 位房间码加入。
   身份就是玩家名称（`profileOf(name)`），同一房间里名称不能重复；加入时带游戏版本号 `GC.version`，和房间不一致就拒绝。
2. 房间里：玩家列表（座位、准备、连通情况）、聊天、房主改设置（模式：新人随机 / 原版数值；出怪口：按人数 / 8 口全开）、房主踢人。
   房主 = 座位最小的人，走了自动顺延。
3. 进房后客户端之间马上建 WebRTC 连接（不等开始）。每人把"我和谁连通了"报给服务器（`links`）；
   全员准备好、全网状都连通，房主才能点开始。
4. 开始：服务器把在场玩家按座位顺序压成 slot 0..N-1，房间状态变 `playing`，之后不能再加入。各客户端从轮询里看到后各自 `GC.startNet(...)` 开局。
5. 对局中继续长轮询（用来发现离开、给断线重连转信令）。标签页关闭时 `sendBeacon` 离开 + 在 `ctl` 上发 `bye`。

## 2. 大厅 / 信令服务（HTTP 长轮询）

| 接口 | 作用 |
|---|---|
| `POST /rooms {name, v}` | 建房，返回 `{code, token, id}` |
| `POST /rooms/{code}/join {name, v}` | 加入（版本不同 409、重名 409、已开始 / 满员 403） |
| `GET /rooms/{code}/poll?token&ver&chat` | 长轮询（25 秒）：房间版本号变了、有新聊天、有给我的信令就返回 `{ver, room, chat, signals}` |
| `POST /rooms/{code}/me {ready, links}` | 改自己的准备状态、上报连通的对端 |
| `POST /rooms/{code}/settings {mode, allGates}` | 房主改设置 |
| `POST /rooms/{code}/chat {text}` | 聊天 |
| `POST /rooms/{code}/kick {id}` | 房主踢人（大厅阶段） |
| `POST /rooms/{code}/signal {to, kind, data}` | 信令中转（offer / answer / ice），对方下一次轮询收到 |
| `POST /rooms/{code}/start` | 房主开始 |
| `POST /rooms/{code}/leave` | 离开 |
| `GET /ice` | STUN / TURN 列表；配了 `TURN_SECRET` 时下发 coturn REST 风格的临时凭证 |

- 除建房 / 加入外都带 `token`（加入时发的私有令牌）；对外只暴露公开的 `id`。30 秒没轮询算掉线，移出房间。
- 结构：`server/room.js` 是纯逻辑的 `Room` 类（一个房间的全部状态和处理函数，不碰 http），`server/server.js` 是 Node 适配层（路由 + 房间表 + CORS）。
  以后搬 Cloudflare：`Room` 放进 Durable Object（一房一个），Worker 只做路由；长轮询可以原样保留或换成 WebSocket。

## 3. 连接层（`h5/net.js`）

- 全网状：每两人一条 `RTCPeerConnection`，`id` 大的一方发 offer。
- 每条连接两个预协商（`negotiated`）的 DataChannel：`ctl`（id 0，可靠有序，JSON 事件）、`snap`（id 1，`ordered:false, maxRetransmits:0`，位置快照；缓冲超过 16KB 丢这一帧）。
- 回退梯子：`direct`（只用 STUN）→ `relay`（只用 TURN，没配 TURN 时跳过）→ `all`，每档 8 秒连不上换下一档；用过中继的设备在 localStorage 记 7 天，下次先走中继。
- `ctl` 上 `_ping/_pong` 测延迟；对端 `ctl` 断开后有 20 秒重连窗口（期间重新走梯子），超时或服务器名单里没有他了，就向游戏报 `leave`。
- 对游戏的接口：`GC_NET.send(ev, to?)`（可靠，广播或单发）、`GC_NET.snap(data, to?)`（不可靠）；收到的交给 `GC.receive(ev, from)` / `GC.snap(data, from)`，`from` 按连接定，不信消息里自报的 slot。
- 标签页在后台时浏览器会停掉 `requestAnimationFrame`：用 Worker 定时器继续推进模拟（`GC.bgTick`），不然这个人口上的怪在别人那里全停住。

## 4. 对局同步：权威划分

| 东西 | 谁算 | 怎么同步 |
|---|---|---|
| 每波的普通出怪（出怪器刷在各口的怪） | 这个口的主人（slot = 口号；主人不在或没人的口归主机） | 主机每次出怪节拍广播 `sp`，各人在自己的口刷怪 |
| BOSS 波的特殊单位、最终波的龙 / 魔王 / 狗头人 | 主机 | 同上，主机自己刷 |
| 怪死后变出来的怪 | 死掉那只的主人 | — |
| 怪的移动、生命、死亡、死亡触发器 | 怪的主人 | `born`（可靠，一次描述）→ `snap` 快照 10 次/秒（id、坐标、生命、朝向）→ `dead` / `gone`（可靠）；不认识的 id 回 `want` |
| 塔 / 英雄 / 召唤物 / 宠物的攻击和技能 | 塔的主人 | 别人那里是"影子"（`G.ghosts`，不攻击）：`tw` 每 0.25 秒发一次增量（新建 / 变化 / 删除），攻击动画走 `snap` 通道 |
| 塔打别人的怪 | 伤害在出手方按代理怪的状态算好，攒成批 `hit` 发给怪的主人扣血 | 10 次/秒一批，同一只怪的伤害合并；主人判定死亡后广播 `dead`，赏金 / 击杀 / 精英奖励 / 掉落归凶手 |
| 减速、晕眩、减甲等状态 | 怪的主人 | 出手方改了代理怪的状态字段 → `mf` 发给主人 → 主人合并后 `ms` 广播；持续伤害（毒、燃烧、区域）留在出手方本地跳，每跳走 `hit` |
| 光环塔对怪 / 对塔的效果、精英光环 | 各端本地算（影子塔和代理怪都参与） | — |
| 波次计时、抽波次、Perfect、怪数上限判负、BOSS 波规则、无尽 | 主机（在线里 slot 最小的） | `clk` 每 0.5 秒（计时、波数、提示、上限、无尽、接管用的检查点）、`wave`（新一波）、`gev`（通关 / 失败 / 兔子等全局事件）、`say`（主机脚本里的提示） |
| 自己的金币 / 木材 / 成就 / 建造栏 | 各人自己（别人动不了） | 别人该给我的（赏金、BOSS 波奖励、卖光环的钱）用 `give` |
| 收购卷轴（两人抢同一座光环） | 主机确认 | 买方 `buy-req` → 主机查这座塔还在、还没卖出 → 广播 `buy`，买方收到才扣钱建塔、卖方收到才拆塔收钱；被拒退回卷轴 |
| 全场唯一的塔（神塔、狂狼塔 / 兽王塔）两人同时建 | 各端按同一规则判：slot 小的保留，另一方自动原价回收 | 靠 `tw` |
| 投票 / 点赞 / 复制 / 踢人 / 聊天 | 发起者广播，各端按同样规则结算 | `vote-start` `vote` `like` `copy` `kick` `chat` |

时间：各端各走各的 `G.t`（联机时不能暂停、不能变速），消息里的"到几时为止"都换成剩余秒数。

## 5. 掉线处理

- 判定：对端发 `bye`、服务器名单里没了、或 `ctl` 断开超过 20 秒 → 各端 `kickPlayer(slot, 离开)`：他的塔（影子）移除，怪物上限每秒 -1（原图行为）。
- 他的怪不消失：当前主机把这些代理怪接过来变成自己的怪（就近找路口接着走），他的出怪口以后也归主机出怪。
- 主机掉线：slot 次小的人自动成为主机，按最后一次 `clk` 里的检查点接管——当前波还没执行的出怪事件、出怪器、下一波预告、BOSS 波规则（已过去的时间扣掉）、最终波（龙 / 魔王从场上现有的怪里认）。
  BOSS 波里只记在旧主机内存里的计数（杀了几只大红牛、飞艇各人击杀数）从 0 重新算。
- 不支持：开始后中途加入、刷新页面后回到原对局（状态在内存里，刷新就没了）。

## 6. 原图多人规则

- 出怪口：默认按人数开（现状）；房间设置里可以选"8 口全开"（原图行为：没人的口也出怪，归主机算，上限仍是 40×人数）。用户已定：默认按人数开。
- 狂狼塔 / 兽王塔：全场只能有一个玩家建。
- `-fuck02`~`-fuck08`：房主（开局 slot 0）直接踢人；`-gb00`：房主不在了，谁先输谁接管房主（之后他能用 `-fuck` / `-KN`）。
- 全场击杀成就（大红牛都是钱 / 大豪猪都是木）：主机按全场击杀计数，达成时全员各得账号成就。

## 7. 已知限制

- 兔子全场同步；小精灵、小偷、野生宠物、地上的掉落物是各人本机的，互相看不到。
- 把别人的怪传走的技能（驱魔塔 / 图腾的遣返）对代理怪只在本地生效一下就被快照拉回，等于无效。
- 天赋秘籍"全场共用 4 个库存"现在是每人各 4 个。
- 伤害在出手方计算，没有防作弊。
