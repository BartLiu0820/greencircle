# 绿色循环圈外传 · H5 复刻

## 怎么玩
直接用浏览器打开 `h5/index.html`（双击即可，不需要服务器、不需要安装任何东西）。

1. 选模式（英雄塔不在开局选：和原图随机模式一样，每次随机建造会给出 1 个英雄塔）：
   - **单人推荐**：38 秒/波，怪物生命 ×0.35，起手 8 人口
   - **原版数值**：33 秒/波，原图数值，起手 6 人口。原图是 8 人合作设计，单人极难
   - **休闲**：50 秒/波，怪物生命 ×0.2，起手 10 人口
   - **多人规模（2~8 人）**：按原图多人局的规模开局（原版数值），N 人开 N 个出怪口、怪物上限 40×N；目前只有你一个人操作，为以后接联机准备
2. 有 60 秒准备时间，先用守卫者在出怪口附近建塔。地图是原图的 8 人地图，单人只开左上角的 1 号出怪口。
3. 操作和 WC3 一样：F1 选中守卫者，点击或右键地面让它移动；在右下角命令面板点"建造"（热键 B）选塔，再点地面，守卫者会走过去建造，按住 Shift 可以连续排队；拖动画面或点小地图移动镜头，滚轮缩放。
4. 场上怪物超过上限就失败（每个玩家 40 只，单人 40）。每波开始时，提示栏会显示护甲类型和克制的攻击类型。
5. 撑过 47 波后是第 48 波最终 BOSS：倒计时 30 秒，之后 300 秒内杀死龙和魔王即通关。

每波开始时，提示栏会预告下一波的"多 / 中 / 少"和护甲类型（和原图一样，倒计时期间就能看到）。

快捷键：P 暂停，空格让镜头对准选中单位，Esc 返回或取消，方向键移动镜头。

## 复刻程度
**照搬原图：**
- 失败规则：怪数 > 40
- 出怪节奏："多 / 中 / 少"分别是 62 只每 0.25 秒、32 只每 0.6 秒、15 只每 1 秒
- 4×4 护甲系数表，护甲公式（系数 0.02）
- 每波生命 +1%
- 精英怪：1/55 概率，5 种光环，额外生命和护甲
- 资源：起手金币和木材，12 木 = 1 人口，木金互换
- 回收返还 100%
- 塔的造价、伤害、攻速、射程，以及辅助、光环、原始塔的技能数值
- 塔的技能按原图触发器实现（`game.js` 的 `KITS`）：
  - 主塔：魔幻塔三种成长（雷霆闪电 / 穿刺之镖 / 混乱流星 + 急速、强攻），神圣塔四种伤害类型 + 神圣攻击 + 魔法容器，寒冰塔冰雹 / 闪冰 / 爆冰 + 冰霜光环 + 关联冰封，天神塔攻击上下限 + 切换伤害类型 + 最高伤害 + 天神之力 + 雷霆一击，剑圣塔剑刃之魂 / 风暴之魂 / 致命一击 + 模式切换，扫射塔 7 级强化
  - 弹跳塔：不占主塔名额，最多 3 座；杀敌 +1 魔法；提升基础攻击 / 攻速（每次 2 木材 + 150 魔法，+60 攻击 / +9% 攻速，对所有弹跳塔生效）；转移魔法；3 座 4 级弹跳塔 + 10000 金合成弹跳塔 MAX（17 个目标、灵魂重击，杀精英 20% 升级）；天赋卷轴激活弹跳天赋后，MAX 回收了再建弹跳塔可花 58000 金直接变成 MAX
  - 功勋和塔的魔法值：杀敌得魔法、木材升功勋、回收返还木材；主塔回收后再建，技能等级和魔法会恢复
  - 原始战速 / 原始战力（按 MAX 原始塔数量升级），通灵塔弹射 3 个，箭塔每 4 击打全体，毒塔持续 20 秒，破坏塔 4 个目标（天赋 9 个）
  - 另类塔：灵魂锁链、图腾之链、召唤精灵、火箭群、巨箭塔转换攻击效果 / 升级伤害
  - 大辅助（萨满、兽人、驱逐、缓速）、巫系（巫医、巫术、巫法、巫魔）、全场唯一（恐惧、火速、神力、冰封、银行、魔法），大辅助进化，驱逐和遣返，天赋卷轴激活大辅助 / 巫系 / 破坏 / 通灵 / 地精塔的天赋
  - 攻击光环等加成只加塔的基础攻击，不放大技能和持续伤害
- 随机建造：7 格（主塔、原始塔、光环塔、新辅助、小辅助、另类塔、全场唯一）+ 1 个英雄塔
- 英雄塔：随机建造按原图 Hc = 1~17 放开 1 个（剑神、大巫师、幻影、战神、水魔、渔人、火魂、狂牛、神牛、电法、箭灵、神幻、邪冰、风神、枪神、坦克、古树），
  原图的建筑造价 1500 金 + 5 木 + 4 人口，全场唯一、建造后不能回收；攻击方式按单位表（溅射、弹射、瞬间命中）
- 17 个英雄的技能都按原图触发器实现（`game.js` 的 `HERO_KITS` / `HERO_DEF`），包括第 5 个特殊技能和它的学习条件，规格见 `analysis/详细玩法拆解.md` 第 7 节：
  - 原图的主动技能都是攻击时自动放（冷却好了就放）；召唤物（影子、鱼人、水元素、炎魔、骷髅、冰龙、火凤……）和马甲按原图的攻击力、间隔、射程、弹射 / 弹幕实现
  - 再次学习：枪神（10000 金）、渔人甲乙丙丁（10000 金）、神牛五个技能（升到 10 级）、神幻（5000 金 + 500 魔法）、狂牛重生点切换自动 / 手动
  - 大巫师的巫祭（献祭巫系塔加属性，献祭巫师塔（光明 / 暗黑）学巫驱 / 巫缓），古树可以多种召唤古树连成清风链条，坦克的能量和火炮 / 轰炸区开关
  - 枪神火焰喷射原图固定朝南，这里改成朝攻击目标
- 塔锁定目标：一直打同一个，直到它死掉或走出射程
- 英雄：建成时随机成长值（力 / 敏 / 智合计 10，每次升级自动加），属性选择决定杀精英 +1 和满级升级 +3 的属性，升级花费（等级 ×100 金 + 200 魔法），每杀 +2 魔法，学技能的木材和力量门槛；
  技能点：建成 3 点，升级时 ≤10 级 +3、≤20 级 +4、≤29 级 +5、30 级 +9，每点力量 / 敏捷 / 智力 +2 或随机；升级时基础攻击 +[力量/5]；攻速加成（敏捷、技能、光环、嗜血一起算）封顶 +400%；大巫师没有属性选择，相关加成都随机一项
- 波次：每波的出怪单位按原图脚本的加权随机抽（`h5/waves.js`），提示词提前一波预告；BOSS 波是第 10、20、30、40 波，第 48 波是最终 BOSS
- 随机建造：第一次免费，之后每次 6 木材
- 路线：双环，路口 50/50 随机
- 地图：原图 8 人地图原样搬过来（坐标就是 WC3 坐标）：外环 ±3840、内环 ±2816，四角 4 个出怪口进外环、中心 4 个出怪口经支路进内环；
  能不能建塔照原图的寻路图（路、出怪口围栏、中央、地图边界不能建）；守卫者出生在地图上方，兔子刷在外环外的四块区域
- 人数：参与 N 人就按原图出怪顺序（I p m o r q n u）开前 N 个出怪口，怪物上限 40×N（原图 C9 / M3）；出怪器每个开着的口各刷 1 只；
  波次里"8 个口各刷 1 只"只在开着的口刷，"1~4 / 5~8 号口随机一个"在其中开着的口里随机，"全图随机一个口"改到开着的口；
  最终波按上限出 1~4 条龙、魔王按人数带护甲 / 生命物品，巨龙 / 魔龙 / 速龙每个口各 1 只；玩家离开时他的上限每秒 -1（联机用）

**简化或改动：**
- 还没有联机：多人规模只是按人数开出怪口和上限，其他玩家的位置是空的。原图 8 个口不管几个人都会出怪，这里改成按人数开放（8 人时和原图一样）。
- 大辅助、巫系、全场唯一和进化后的塔还没有原版模型（显示为方块），要用 `tools/war3_batch.py` 补渲染。
- 荣誉光环、原始塔的天赋（牛头 / 群攻 / 闪电 / 箭塔）、图腾塔 MAX 随魔法值提升技能等级未实现。
- 英雄塔只做了随机模式会放开的 17 个（原图有 44 个，另外 17 个要"英雄赞助"，其余是平台英雄）。
- 英雄塔要 10 点当局成就才能建，建成扣 10 点（原图随机模式 17 个英雄都这样）。开局输入玩家名称，同名继承本机存的账号成就点数（每到达新的一波 +1、每次 Perfect +1、通关 +30），按档位开局多给 0~10 点当局成就。
- 英雄的召唤物和马甲没有原版模型，显示为带字的圆点；原图里会走动的炎魔 / 水元素 / 骷髅这里会走向射程外最近的敌人。
- 原图触发器里有几处条件优先级写错了，照搬（在 `game.js` 注释里标明）：大巫师放死亡呐喊 / 巫驱每次都刷新冷却，坦克学了轰炸区后所有塔的攻击都给能量，幻影近战影子不学智力魔击也有附加伤害，坦克杀精英不需要战争科技也 +3 力量。
- 平台账号系统（至尊、段位、宠物、许愿、皮肤）去掉；账号成就换成本地玩家档案（见上）。
- 无尽模式未实现。

## 重新生成数据
需要先用分析脚本把地图解包，得到 `units.json`、`abilities.json` 和 `waves_raw.json`，然后运行：
```bash
python3 tools/gen_data.py <包含 units.json / abilities.json / waves_raw.json 的目录>
```
大辅助、巫系、全场唯一塔和进化后的塔由另一个脚本补进 `data.js`（gen_data.py 之后运行）：
```bash
python3 tools/add_towers.py
```
英雄由另一个脚本写进 `data.js`（gen_data.py 之后运行）：
```bash
python3 tools/add_heroes.py
```
波次数据直接从仓库里的标注版脚本生成（gen_data.py 之后再跑一次）：
```bash
python3 tools/wave_rolls.py
```
地图布局（寻路图、地块、树、区域）直接从仓库根目录的地图包导出：
```bash
python3 tools/war3_map.py
```
