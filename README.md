# 绿色循环圈外传 · H5 复刻

## 怎么玩
直接用浏览器打开 `h5/index.html`（双击即可，不需要服务器、不需要安装任何东西）。

1. 选模式（英雄塔不在开局选：和原图随机模式一样，每次随机建造会给出 1 个英雄塔）：
   - **新人随机**：原图的新人随机模式（原图在半数以上玩家荣誉少于 30 时自动开启）：起手多 2000 金、7 木、2 人口（4000 金 / 12 木 / 8 人口），38 秒/波，每 5 秒发金翻倍（名次×12 + 波数×4），最终波魔王不带按人数加的护甲 / 生命物品；怪物生命是原图数值
   - **原版数值**：33 秒/波，原图数值，起手 6 人口。原图是 8 人合作设计，单人极难
   - **休闲**：50 秒/波，怪物生命 ×0.2，起手 10 人口
   - **多人规模（2~8 人）**：按原图多人局的规模开局（原版数值），N 人开 N 个出怪口、怪物上限 40×N；还没有联机，其他位置可以空着（实际只有你一人），也可以放"模拟队友"（站在出生点不操作，用来试复制 / 收购卷轴、投票踢人、点赞、杀敌排行）
2. 有 60 秒准备时间，先用守卫者在出怪口附近建塔。地图是原图的 8 人地图，单人只开左上角的 1 号出怪口。
3. 操作和 WC3 一样：F1 选中守卫者，点击或右键地面让它移动；在右下角命令面板点"建造"（热键 B）选塔，再点地面，守卫者会走过去建造，按住 Shift 可以连续排队；拖动画面或点小地图移动镜头，滚轮缩放。
4. 场上怪物超过上限就失败（每个玩家 40 只，单人 40）。每波开始时，提示栏会显示护甲类型和克制的攻击类型。
5. 撑过 47 波后是第 48 波最终 BOSS：倒计时 30 秒，之后 300 秒内杀死龙和魔王即通关。

每波开始时，提示栏会预告下一波的"多 / 中 / 少"和护甲类型（和原图一样，倒计时期间就能看到）。

快捷键：P 暂停，空格让镜头对准选中单位，Esc 返回或取消，方向键移动镜头。

## 复刻程度
**照搬原图：**
- 失败规则：怪数 > 40
- 出怪节奏："多 / 中 / 少"分别是 62 只每 0.25 秒、32 只每 0.6 秒、15 只每 1 秒
- 4×4 护甲系数表，护甲公式（系数 0.02）
- 每波生命 +1%
- 怪物死亡掉落（原图 wa，每只 1~5000 随机）：木 6/5000、钱 11/5000，上 / 有 / 马 / 光环碎片各 1/5000，梦 1/25000，魔法药水（小）5/5000；
  魔法药水（小）对有魔法功勋的塔 +50 魔法（天神塔不能用），3 个自动合成魔法药水
- 精英怪：1/55 概率，5 种光环，额外生命和护甲
- 资源：起手金币和木材，12 木 = 1 人口，木金互换
- 回收返还 100%
- 塔的造价、伤害、攻速、射程，以及辅助、光环、原始塔的技能数值
- 塔的技能按原图触发器实现（`game.js` 的 `KITS`）：
  - 主塔：魔幻塔三种成长（雷霆闪电 / 穿刺之镖 / 混乱流星 + 急速、强攻），神圣塔四种伤害类型 + 神圣攻击 + 魔法容器，寒冰塔冰雹 / 闪冰 / 爆冰 + 冰霜光环 + 关联冰封，天神塔攻击上下限 + 切换伤害类型 + 最高伤害 + 天神之力 + 雷霆一击，剑圣塔剑刃之魂 / 风暴之魂 / 致命一击 + 模式切换，扫射塔 7 级强化 + 炮（炮击减速，被炮中的敌人挨树魔猎手打多一份混乱伤害）+ 巨魔蝙蝠（召唤树魔猎手），炮 / 巨魔各 8 级、回收再建保留等级
  - 随机模式主塔池补全到原图的 17 种（Qf = 1~17）：另外 10 种按原图触发器实现——
    - 风行塔：暴力箭 / 疯狂箭 / 削甲箭（切换技能吃魔法升级），放技能攒多重箭次数、抉择按场上怪数定目标数，天赋打开 8000 通用伤害的第二武器
    - 将军塔 / 天将塔：卒 / 炮 / 马 / 車 / 象 / 士 召唤类技能，切换技能吃魔法升级（4 级后共存），照搬原图切换时关闭技能的规则；天将的"士"是攻击 / 攻速科技；将军 MAX 天赋军令状
    - 狂狼塔：致命 / 野性（小狼崽光环）/ 兽性 / 噬性，杀敌时升级，狼族力量科技，天赋疯狂之狼变身

需要先用分析脚本把地图解包，得到 `units.json`、`abilities.json` 和 `waves_raw.json`，然后运行：
```bash
python3 tools/gen_data.py <包含 units.json / abilities.json / waves_raw.json 的目录>
```
大辅助、巫系、全场唯一塔和进化后的塔由另一个脚本补进 `data.js`（gen_data.py 之后运行）：
```bash
python3 tools/add_towers.py
```
英雄由另一个脚本写进 `data.js`（gen_data.py 之后运行）：
```bash
python3 tools/add_heroes.py
```
无尽关卡的 10 种怪物（add_heroes.py 之后运行，再用 `tools/war3_batch.py` 出精灵表）：
```bash
python3 tools/add_endless.py
```
怪物的被动（闪避 / 魔法免疫 / 硬化皮肤）和触发器刷出来的单位（add_endless.py 之后运行，再用 `tools/war3_batch.py --cats=monster` 出精灵表）：
```bash
python3 tools/add_monster_extra.py
```
波次数据直接从仓库里的标注版脚本生成（gen_data.py 之后再跑一次）：
```bash
python3 tools/wave_rolls.py
```
地图布局（寻路图、地块、树、区域）直接从仓库根目录的地图包导出：
```bash
python3 tools/war3_map.py
```
